# Django Project

## Description
A simple Django web application with user authentication.

---

## Installation

```bash
git clone https://github.com/mightyygene/django-project.git
cd django-project
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
---

## Running the Project

```bash
cd config
python manage.py migrate
python manage.py runserver
```

---

## Access

Open in your browser:

http://127.0.0.1:8000/
